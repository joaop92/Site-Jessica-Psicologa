# Site — Jéssica, Psicóloga Infantil e do Adolescente

Site em React + Vite para a psicóloga Jéssica.

## Rodar localmente

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
```

## Antes de publicar, edite `src/siteConfig.js`

- `sobrenome`
- `crp`
- `whatsapp` (DDI+DDD+número, só dígitos, ex: 5581999999999)
- `whatsappDisplay`
- `instagram`
- `email`
- `cidade`

Também revise os textos de exemplo em `src/components/Sobre.jsx` (tempo de experiência) e nas demais seções.
